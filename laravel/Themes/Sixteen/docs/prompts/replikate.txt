## 🏗️ Architettura del Sistema

### Principi Fondamentali

```
┌─────────────────────────────────────────────────────────────┐
│                    USER REQUEST                             │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  APP_URL → Domain Parsing → Config Path → pub_theme        │
│  fixcity.local → local/fixcity → config/local/fixcity/     │
│  xra.php → pub_theme = "Sixteen"                           │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  Laravel Folio reads:                                       │
│  Themes/Sixteen/resources/views/pages/tests/[slug].blade.php│
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  Volt Component mounts → Reads JSON content:                │
│  config/local/fixcity/database/content/pages/tests.*.json   │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  <x-page side="content" :slug="$pageSlug" :data="$data" />  │
│  Renders universal blocks from JSON                         │
└─────────────────────────────────────────────────────────────┘
```

### Regole d'Oro

> ✅ **SEMPRE:** `<x-layouts.app>` (estende `<x-layouts.main>`)
> 
> ❌ **MAI:** `<x-layouts.design-comuni>` o `<x-pub_theme::layouts.*>`

> ✅ **SEMPRE:** `Themes/Sixteen/resources/views/pages/tests/[slug].blade.php`
> 
> ❌ **MAI:** `homepage.blade.php`, `amministrazione.blade.php` (file specifici)

> ✅ **SEMPRE:** Blocchi universali (`hero`, `card`, `topics-grid`)
> 
> ❌ **MAI:** Blocchi pagina-specifici (`tests.argomenti.*`)

## ⚡ Vite Build System

### 🔴 Errore Comune

```blade
{{-- SBAGLIATO: Cerca in public_html/build/manifest.json --}}
@vite(['resources/css/app.css', 'resources/js/app.js'])
```

### ✅ Soluzione Corretta

```blade
{{-- CORRETTO: Cerca in public_html/themes/Sixteen/build/manifest.json --}}
@vite(['resources/css/app.css', 'resources/js/app.js'], 'themes/Sixteen')
```

### Configurazione Vite

**File:** `laravel/Themes/Sixteen/vite.config.js`

```javascript
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';

export default defineConfig({
  build: {
    outDir: './public',  // Genera in themes/Sixteen/public/build/
    manifest: true,       // Crea manifest.json
  },
  plugins: [
    laravel({
      input: ['resources/css/app.css', 'resources/js/app.js'],
      refresh: true,
    }),
  ],
});
```

**File:** `laravel/Themes/Sixteen/package.json`

```json
{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "copy": "cp -rv ./public/* ../../../public_html/themes/Sixteen/"
  }
}
```

### 🐛 Risoluzione Errori Vite Manifest

```bash
# Se vedi: Vite manifest not found at: public_html/themes/Sixteen/manifest.json
cd laravel/Themes/Sixteen
composer update -W
npm install
npm run build
npm run copy
```

**Perché funziona:**
1. `outDir: './public'` → Vite genera in `themes/Sixteen/public/build/manifest.json`
2. `npm run copy` → Sincronizza con `public_html/themes/Sixteen/`
3. `@vite([...], 'themes/Sixteen')` → Cerca nel percorso corretto

## 🔍 Theme Detection

### Algoritmo di Rilevamento

```php
// 1. Leggi APP_URL da .env
$appUrl = env('APP_URL', 'http://fixcity.local');

// 2. Rimuovi protocollo
$domain = str_replace(['http://', 'https://'], '', $appUrl);

// 3. Rimuovi www
$domain = str_replace('www.', '', $domain);

// 4. Explode e inverti
$parts = array_reverse(explode('.', $domain));

// 5. Unisci con "/"
$configPath = implode('/', $parts); // "local/fixcity"

// 6. Leggi configurazione
$pubTheme = config('xra.pub_theme'); // Da config/local/fixcity/xra.php
// Risultato: "Sixteen" → Themes/Sixteen/
```

**File:** `config/local/fixcity/xra.php`

```php
return [
    'pub_theme' => 'Sixteen',
    // ...
];
```

## 📄 Page Routing con Folio + Volt

### Template Universale [slug].blade.php

**File:** `Themes/Sixteen/resources/views/pages/tests/[slug].blade.php`

```blade
<?php

declare(strict_types=1);

use function Laravel\Folio\middleware;
use function Laravel\Folio\name;
use Livewire\Volt\Component;
use Modules\Cms\Http\Middleware\PageSlugMiddleware;

name('tests.view');
middleware(PageSlugMiddleware::class);

new class extends Component {
    public string $slug = '';
    public string $pageSlug = '';

    /** @var array<string, mixed> */
    public array $data = [];

    public function mount(string $slug): void
    {
        $this->slug = $slug;
        $this->pageSlug = 'tests.'.$slug;
        $this->data = [
            'slug' => $slug,
        ];
    }
};

?>

<x-layouts.app>
    @volt('tests.view')
        <div>
            <x-page side="content" :slug="$pageSlug" :data="$data" />
        </div>
    @endvolt
</x-layouts.app>
```

{{-- ❌ SBAGLIATO: Blocco pagina-specifico --}}

## 🔍 Quality Assurance

### Screenshot & Analisi

Per ogni pagina replicata:

1. **Crea screenshot** di originale e replica
2. **Salva in:** `Themes/Sixteen/docs/screenshots/<pagina>/`
   - `originale.png`
   - `replica.png`
   - `confronto.png`
3. **Crea analisi:** `Themes/Sixteen/docs/screenshots/<pagina>/<pagina>.md`

**Template Analisi:**

```markdown
# Analisi: [Nome Pagina]

## Differenze Rilevate

### Header
- ❌ Logo non visibile
- ❌ Colori diversi (#0066CC vs #003366)
- ❌ Spaziatura: 16px vs 24px

### Footer
- ❌ Colonne non allineate
- ❌ Font-size: 14px vs 16px

## Come Correggere

1. Aggiornare `style-apply.css` con:
   ```css
   .it-header-slim-wrapper {
       @apply bg-[#003366]; /* Colore corretto */
   }
   ```

2. Compilare:
   ```bash
   npm run build
   npm run copy
   ```

3. Verificare con screenshot
```

## 🤖 Agent Collaboration

### Agent Specializzati

Questo task coinvolve multipli agenti AI:

| Agente | Responsabilità |
|--------|---------------|
| **gsd-codebase-mapper** | Mappatura codebase esistente |
| **gsd-ui-researcher** | Ricerca pattern UI Design Comuni |
| **gsd-ui-checker** | Verifica conformità UI |
| **gsd-executor** | Esecuzione piano di lavoro |
| **gsd-verifier** | Verifica risultato finale |
| **gsd-nyquist-auditor** | Generazione test di copertura |

### Strumenti Consigliati

**Installare e configurare:**

```bash
# MCP Servers (configurare in mcp.json)
npm install -g @anthropic-ai/mcp-server-filesystem
npm install -g @anthropic-ai/mcp-server-screenshot

# Skills
# https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
# https://github.com/bencium/bencium-claude-code-design-skill
# https://smithery.ai/skills/vnzzzz/frontend-design
```

**Configurazione MCP:**

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@anthropic-ai/mcp-server-filesystem", "/var/www/_bases/base_fixcity_fila5"]
    },
    "screenshot": {
      "command": "npx",
      "args": ["-y", "@anthropic-ai/mcp-server-screenshot"]
    }
  }
}
```

### Workflow Multi-Agente

```
1. gsd-codebase-mapper → Analizza struttura esistente
2. gsd-ui-researcher → Studia Design Comuni patterns
3. gsd-planner → Crea piano di implementazione
4. gsd-executor → Esegue implementazione
5. gsd-ui-checker → Verifica conformità visiva
6. gsd-nyquist-auditor → Genera test
7. gsd-verifier → Verifica risultato finale
```

## Theme Detection Process

1. Read `laravel/.env` → `APP_URL=http://fixcity.local`
2. Extract domain: `fixcity.local` → explode `.` → reverse → join `/` → `fixcity/local`
3. Read `base_path('config/fixcity/local/xra.php')`

## Architecture Principles (DRY + KISS)

### ONE Dynamic Route File - NEVER Specific Files

**CORRECT**:
```
laravel/Themes/Sixteen/resources/views/pages/tests/[slug].blade.php
```
This handles ALL 38 pages dynamically.

**WRONG** (NEVER do this):
```
tests/homepage.blade.php
tests/amministrazione.blade.php
tests/argomenti.blade.php
```

### Dynamic Route Implementation

```php
<?php

declare(strict_types=1);

use function Laravel\Folio\middleware;
use function Laravel\Folio\name;
use Livewire\Volt\Component;
use Modules\Cms\Http\Middleware\PageSlugMiddleware;

name('tests.view');
middleware(PageSlugMiddleware::class);

new class extends Component {
    public string $slug = '';
    public string $pageSlug = '';

    /** @var array<string, mixed> */
    public array $data = [];

    public function mount(string $slug): void
    {
        $this->slug = $slug;
        $this->pageSlug = 'tests.'.$slug;
        $this->data = ['slug' => $slug];
    }
};
?>
<x-layouts.app>
    @volt('tests.view')
        <div>
            <x-page side="content" :slug="$pageSlug" :data="$data" />
        </div>
    @endvolt
</x-layouts.app>
```

---

## Components vs Sections

| Type | Usage | Examples |
|------|-------|----------|
| **Section** | Global structures | `<x-section slug="header" />`, `<x-section slug="footer" tpl="slim" />` |
| **Block** | Reusable UI components | `hero`, `card`, `grid`, `steps` |
| **Layout** | Page container | `<x-layouts.app>` extends `<x-layouts.main>` |

### Layout Hierarchy

```blade
<x-layouts.app>                    {{-- Themes/Sixteen/resources/views/components/layouts/app.blade.php --}}
    ├── <x-section slug="header" />  {{-- Header section --}}
    ├── @volt('tests.view')          {{-- Livewire Volt component --}}
    │    └── <x-page side="content" :slug="$pageSlug" :data="$data" />
    └── <x-section slug="footer" />  {{-- Footer section --}}
</x-layouts.app>
```

## 🎓 Lezioni Apprese

### Architettura
1. **Vite Build:** `outDir: './public'` + `npm run copy` è la soluzione corretta
2. **Folio + Volt:** `[slug].blade.php` dinamico è meglio di file specifici
3. **JSON Content:** CMS-driven pages con blocchi universali

### Documentazione
1. **Bidirezionalità:** Ogni documento deve avere 3+ cross-reference
2. **Esempi:** Codice copiabile e testabile
3. **Struttura:** Indici gerarchici per navigazione facile

### Agent Collaboration
1. **Multi-Agent:** Task coinvolge più agenti AI
2. **Context Sharing:** Documentazione condivisa aiuta collaborazione
3. **Verification:** Ogni agente può verificare e migliorare
