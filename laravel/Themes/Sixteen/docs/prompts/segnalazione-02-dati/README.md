## How to Run the Comparison

### Prerequisites
1. Ensure local server is running: `cd laravel && php artisan serve --host=127.0.0.1 --port=8000`
2. Ensure the local page renders correctly at `http://127.0.0.1:8000/it/tests/segnalazione-02-dati`

### Run Comparison
```bash
# From project root
bashscripts/html/html-structure-compare.sh segnalazione-02-dati
```

This will:
1. Fetch local HTML from `http://127.0.0.1:8000/it/tests/segnalazione-02-dati`
2. Compare against `reference_segnalazione-02-dati.html` (already present)
3. Generate artifacts in `body-structure-comparison/`:
   - `reference.html` — Reference body (no `<script>`/`<style>`)
   - `local.html` — Local body (no `<script>`/`<style>`)
   - `struct1_*.txt` / `struct2_*.txt` — Parsed structure trees
   - `diff_*.txt` — Structural differences
   - `report_*.md` — Human-readable parity report
   - `blocks1_*.json` / `blocks2_*.json` — Machine-readable block data

### View Results
- Parity score and findings: `html-parity-analysis.md` (update manually after review)
- Detailed report: `body-structure-comparison/report_*.md`
- Body comparison index: `../../body-structure-comparison/INDEX.md`
