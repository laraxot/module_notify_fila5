# 📚 Design Comuni - Documentazione Index

Benvenuti nella documentazione del progetto **Design Comuni Integration** per FixCity.

## 🎯 Panoramica

Questo progetto integra le **39 pagine** del design system Bootstrap Italia nel tema **Sixteen** di FixCity, utilizzando **Tailwind CSS 4 + Vite + DaisyUI**.

**Fonte**: [Italia Design Comuni](https://italia.github.io/design-comuni-pagine-statiche/)  
**Stato**: In Sviluppo (2/39 pagine completate)  
**Timeline**: 15 giorni stimati
