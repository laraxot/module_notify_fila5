## 🎯 The Process

### When to Build

Build required when you modify:
- ✅ CSS files (`resources/css/*.css`)
- ✅ JavaScript files (`resources/js/*.js`)
- ✅ Blade components with inline styles
- ✅ Tailwind configuration
- ✅ AGID variables

### Build Commands

```bash
# Navigate to theme directory
cd laravel/Themes/Sixteen

# 1. Install dependencies (first time only)
npm install

# 2. Build for development (with sourcemaps)
npm run build

# 3. Copy to public_html
npm run copy
```

### What Each Command Does

#### `npm install`
- Installs Node.js dependencies
- Creates `node_modules/` folder
- Only needed once or when package.json changes

#### `npm run build`
- Compiles Tailwind CSS → `public/assets/app-[hash].css`
- Bundles JavaScript → `public/assets/app-[hash].js`
- Generates `public/manifest.json`
- Adds content hashes for cache busting

**Output**:
```
public/
├── assets/
│   ├── app-B76fg-d3.js        # JavaScript bundle
│   ├── app-OqwgGNrR.css       # CSS bundle
│   └── vendor-ui-B_AfaIMK.js  # Vendor bundle
└── manifest.json               # Vite manifest
```

#### `npm run copy`
- Copies built assets to `public_html/themes/Sixteen/`
- Creates directory structure
- Preserves manifest.json

**Output**:
```
public_html/themes/Sixteen/
├── assets/
│   ├── app-[hash].js
│   ├── app-[hash].css
│   └── vendor-[hash].js
├── manifest.json
└── site.webmanifest
```

## 🔄 Development Workflow

### Option 1: Build + Copy (Recommended)

```bash
cd laravel/Themes/Sixteen

# Make your CSS/JS changes
# Edit: resources/css/agid-variables.css

# Build
npm run build

# Copy to public_html
npm run copy

# Test in browser
firefox http://fixcity.local/it/tests/argomenti
```

### Option 2: Development Mode (Watch)

```bash
cd laravel/Themes/Sixteen

# Start watch mode (auto-rebuild on changes)
npm run dev

# In another terminal, copy on change
npm run copy
```

**Benefits**:
- ✅ Auto-rebuild on file changes
- ✅ Fast iteration
- ✅ Sourcemaps for debugging

## 🎨 Example: Adding AGID Color

### Step 1: Add to Variables

**File**: `resources/css/agid-variables.css`

```css
:root {
    --agid-custom: #FF5733;  /* New color */
}
```

### Step 2: Use in Component

**File**: `resources/views/sections/header.blade.php`

```blade
<div style="background-color: var(--agid-custom);">
    <!-- Content -->
</div>
```

### Step 3: Build & Publish

```bash
cd laravel/Themes/Sixteen
npm run build
npm run copy
```

### Step 4: Test

```bash
# Clear browser cache
Ctrl+Shift+R (hard refresh)

# Verify color changed
firefox http://fixcity.local/it/tests/argomenti
```

## 🔧 Troubleshooting

### Problem: Changes Not Visible

**Solution**:
```bash
# 1. Clear Laravel cache
php artisan view:clear
php artisan cache:clear

# 2. Clear browser cache
Ctrl+Shift+R

# 3. Verify manifest.json
cat public_html/themes/Sixteen/manifest.json

# 4. Rebuild
npm run build
npm run copy
```

### Problem: CSS Not Compiling

**Solution**:
```bash
# 1. Check for syntax errors
# Edit: resources/css/app.css

# 2. Check imports
@import "./agid-variables.css";  # Must exist

# 3. Rebuild with verbose output
npm run build -- --debug
```

### Problem: Manifest Not Found

**Solution**:
```bash
# 1. Verify build completed
ls -la laravel/Themes/Sixteen/public/manifest.json

# 2. Verify copy completed
ls -la public_html/themes/Sixteen/manifest.json

# 3. Re-run copy
npm run copy
```

## 🚀 Best Practices

### DO ✅

- ✅ Build before testing
- ✅ Copy after build
- ✅ Clear cache after changes
- ✅ Use version hashes
- ✅ Test in incognito mode

### DON'T ❌

- ❌ Edit files in `public/` or `public_html/`
- ❌ Skip build step
- ❌ Forget to copy
- ❌ Edit manifest.json manually
- ❌ Test without cache clear
