## Sezione 2: BLOCCHI COMUNI IDENTIFICATI

### Header

| Variante | Descrizione | Pagine |
|----------|-------------|--------|
| `it-header-slim` | Header slim con logo e link rapidi | Homepage, tutte le pagine |
| `it-header-center` | Header centralizzato con navigazione completa | Servizi, dettagli |
| `it-header-nav` | Header con navigazione espansa | Amministrazione, Servizi |

**Struttura tipica:**
- Logo comune (sx)
- Link utili (area personale, cerca, contatta)
- Menu navigazione principale
- Megamenu per categorie

### Footer

| Variante | Descrizione | Pagine |
|----------|-------------|--------|
| `it-footer` | Footer standard con multiple colonne | Tutte le pagine |

- Colonna 1: Logo + descrizione + link social
- Colonna 2: Linkservizi rapidi

- Bottom bar: Copyright + link privacy

## Note di Implementazione

### Stack Tecnologico
- Bootstrap Italia (versione comuni)
- CSS personalizzato in `bootstrap-italia-comuni.css`
- Componenti React/Tailwind per modernizzazione

### Pattern Ricorrenti
- Sidebar di navigazione sticky con `it-navscroll-wrapper`
- Tabs per separare sezioni (Sito / Flussi)
- Liste con `it-list` + `it-right-zone`
- Card con `it-card` e varianti

### Responsive
- Mobile-first con breakpoint Bootstrap Italia
- Navbar collapsible su mobile
- Griglia: `col-12` → `col-md-4/8`
